This is a project inspired by those videos of visualizing sorting algorithms. I loved how satisfying it sounded while it sorted and how clean it looked.
It's also a good way for me to practice my frontend and logic after a long school year. 

While similar projects do exist, this helps me practice my creativity on some more unconventional sorting methods that nobody has made before.
The first "polished" stage of the project should include many other additions other than just watching sorting algorithim.

This is an ongoing project and I plan to continue adding practical, silly and or original sorting methods along with other features such as trivia, history, and code segments to help people learn how the algorithim really works!
Eventually I plan to add other features like multiplayer versus but that will come in the further future. 

Thanks for reading!
